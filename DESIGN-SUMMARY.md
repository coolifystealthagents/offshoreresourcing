# Design summary

- Design concept: Resourcing lab
- Layout personality: data-driven dashboard
- Typography: Space Grotesk headings with DM Sans body text
- Color palette: primary #312e81, secondary #818cf8, accent #14b8a6, background #eef2ff, text #1e1b4b, muted #64748b
- Shape language: Large rounded cards
- Visual motif: data tiles and resource meters
- Unique layout choices: first sections use Capacity lab, then a custom service index, process ribbon, question block, and resource strip with varied widths and alignments.
- Difference from previous sites: this redesign changes the hero composition, section ordering, image treatment, card style, spacing rhythm, button shape, and footer treatment for this domain.
