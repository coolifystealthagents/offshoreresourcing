## Key stats
- A table should answer one comparison question.
- Every number needs a unit, period, and source context.
- Short labels improve scanning without removing necessary qualifications.
## Key takeaways
- Put the decision field first.
- Keep definitions close to the table.
- Do not imply precision beyond the source.
## Table routine
Start with the claim register and turn only comparable fields into columns. Link to the [content fact checking evidence matrix](/research/content-fact-checking-evidence-matrix) for review.
| Field | Check | Example |
| --- | --- | --- |
| Measure | Same definition | Rate |
| Period | Same window | 2025 |
| Unit | Visible | Percent |
| Source | Traceable | Primary link |
## Methodology and limitations
This guidance applies public research, statistics, accessibility, search, and plain-language principles. Tables cannot resolve incompatible source definitions by themselves.

## FAQs
### How many columns should a table have?
Use only the columns needed for the reader decision. Move explanation into notes when the table becomes difficult to scan.
### Should estimates be shown?
Only when the method and uncertainty are clearly labeled.
