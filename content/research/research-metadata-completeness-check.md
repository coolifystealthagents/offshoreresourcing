## Key stats

- Six metadata fields should be checked before release: title, description, date, image, canonical, and schema.
- Google Search Essentials treats technical requirements, spam policies, and key best practices as separate checks.
- Metadata describes a page; it cannot rescue unsupported content.

## Key takeaways

- Check identity fields before copy edits.
- Keep the canonical URL stable after publication.
- Validate structured data against the rendered article data.

## Check matrix

| Field | Failure mode | Proof |
| --- | --- | --- |
| Title | Ambiguous or duplicated | Title index |
| Description | Missing intent | Frontmatter review |
| Date | Not real or stale | Verification record |
| Canonical | Wrong family path | URL comparison |

## Operating method

Run the [offshore SEO research controls](/research/offshore-seo-research-controls) after the content validator and before commit. Compare against existing Research slugs and titles so the family stays distinct from Blog and Alternatives. Record every corrected field in the batch log.
