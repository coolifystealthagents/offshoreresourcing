## Key stats

- A good table has one comparison purpose and a clear unit or definition.
- Headers should explain the meaning of every value without requiring guesswork.
- Source notes belong close enough to the table for readers to trace them.

## Key takeaways

- Avoid mixing observed measures with recommendations in one column.
- Use consistent labels across an article cluster.
- Check narrow-screen readability before publication.

## Table checklist

| Check | Pass condition |
| --- | --- |
| Purpose | Reader can name the comparison |
| Units | Values use defined units |
| Scope | Population and dates are visible |
| Evidence | Source note is traceable |

The [table design guide](/research/research-table-design-for-claims) and [content accessibility review](/research/content-accessibility-review) cover implementation.
