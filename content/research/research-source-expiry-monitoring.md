## Key stats

- Every source record needs a checked date and a next-review rule.
- A broken link is a discoverability issue; an outdated claim is an evidence issue.
- Review priority should reflect claim impact, not only article age.

## Key takeaways

- Tag sources as evergreen, monitored, or time-sensitive.
- Recheck primary sources before secondary summaries.
- Record whether a changed source affects wording, numbers, or conclusions.

## Monitoring queue

| Signal | First action | Disposition |
| --- | --- | --- |
| URL fails | Locate canonical page | Replace or remove |
| Date passes | Reopen claim | Confirm or revise |
| Method changes | Reassess claim | Add context |
| Publisher changes | Verify authority | Retain or retire |

Use the [maintenance routines](/research/knowledge-base-maintenance-routines) and [link integrity routine](/research/research-link-integrity-routine) as the operating pair.
