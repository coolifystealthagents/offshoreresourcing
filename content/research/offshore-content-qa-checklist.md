## Key stats

- QA is stronger when checks are observable and repeatable.
- Content can be factually correct and still fail on links or metadata.
- Rechecking after edits catches defects introduced during cleanup.

## Key takeaways

- Run content, link, and metadata checks as separate passes.
- Keep a failure record with owner and correction.
- Revalidate the final file, not only the draft version.

## Final-pass table

| Area | Pass condition |
| --- | --- |
| Facts | Claims map to reviewed sources |
| Structure | Required sections are present |
| Links | Internal and external links resolve |
| Metadata | Title, description, date, and image exist |

Use the [source verification workflow](/research/source-verification-workflow) and [review SLA](/research/offshore-editorial-review-sla) to assign failures.
