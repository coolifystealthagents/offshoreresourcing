## Key stats
- A handoff is complete only when the next owner can act without guessing.
- Source links, status, and next action are the minimum useful handoff fields.
- Clear rejection reasons reduce repeat corrections.
## Key takeaways
- Define acceptance before work begins.
- Return incomplete evidence with one actionable reason.
- Keep ownership visible across time zones.
## Acceptance checklist
Compare each handoff with the [remote writer handoff controls](/research/remote-writer-handoff-controls).
| Check | Pass condition |
| --- | --- |
| Brief | Purpose and audience are clear |
| Evidence | Sources and claims are mapped |
| Draft | Required sections are present |
| Next step | Owner and deadline are named |
## Methodology and limitations
This checklist synthesizes public quality, research, search, accessibility, privacy, and security guidance. It supports workflow consistency but does not assess subject expertise.

## FAQs
### Who accepts the handoff?
The owner of the next quality gate should accept or return it, with an explicit reason.
### What if the owner is unavailable?
Use the named backup and log the substitution.
