## Key stats

- Handoffs fail when context remains in private conversations.
- A required-field checklist exposes missing inputs early.
- One accountable receiver is clearer than a shared queue with no owner.

## Key takeaways

- Include brief, sources, claims, open questions, and next action.
- Link to the canonical working file and identify its revision.
- Escalate ambiguity instead of asking the writer to infer it.

## Handoff contents

| Item | Minimum evidence |
| --- | --- |
| Brief | Intent, audience, scope |
| Research | Source list and claim notes |
| Draft state | Word count and known gaps |
| Ownership | Sender, receiver, deadline |

The [source workflow](/research/source-verification-workflow) supports claim notes; the [onboarding controls](/research/offshore-team-onboarding-controls) define access boundaries.
