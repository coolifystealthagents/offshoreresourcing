## Key stats

- A source library should preserve context, not just URLs.
- Tags for topic, authority, date, and use make later review faster.
- Reuse still requires checking whether the source supports the new claim.

## Key takeaways

- Store source title, publisher, URL, date, and notes.
- Record which claims the source supports and which it does not.
- Review high-impact entries on a defined schedule.

## Library fields

| Field | Purpose |
| --- | --- |
| Publisher | Establishes authority |
| Topic | Enables relevant discovery |
| Verified date | Shows freshness |
| Claim note | Prevents overextension |

The [maintenance routine](/research/knowledge-base-maintenance-routines) defines review; the [source workflow](/research/source-verification-workflow) defines acceptance.
