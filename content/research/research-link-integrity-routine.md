## Key stats
- A link can fail through removal, redirection, scope change, or typo.
- Internal links should add context rather than repeat navigation.
- Citation checks belong in the final validation pass.
## Key takeaways
- Check links after slug changes.
- Revisit external sources when evidence is refreshed.
- Keep related cards within the same Research family.
## Integrity routine
Use the [research article internal link map](/research/research-article-internal-link-map) to record destination, purpose, and check date.
| Link type | Check |
| --- | --- |
| Source | Resolves to supporting authority |
| Contextual | Adds a useful next step |
| Related | Matches topic and family |
| Canonical | Uses the stable path |
## Methodology and limitations
This routine uses public search, research, accessibility, quality, privacy, and plain-language guidance. Link resolution alone does not prove that a source supports a claim.

## FAQs
### How often should links be checked?
Check before publication and whenever a linked article, source, or route changes.
### What should happen to a dead source?
Find an authoritative replacement, update the claim if needed, and record the change.
