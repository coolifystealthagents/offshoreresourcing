## Key stats

- Three evidence roles make a claim easier to test: primary data, independent context, and method guidance.
- A source count alone cannot prove quality.
- Pew Research publishes methods alongside findings to make interpretation inspectable.

## Key takeaways

- Prefer primary sources for headline numbers.
- Use independent context to identify limitations.
- Write the article claim only as strongly as the evidence permits.

## Triangulation pattern

| Role | Question | Record |
| --- | --- | --- |
| Primary | Who collected the data? | Dataset or report |
| Context | Does another source agree? | Independent link |
| Method | How should it be interpreted? | Method note |

## Operating method

Create a claim row before drafting. Link it to the [content fact-checking evidence matrix](/research/content-fact-checking-evidence-matrix), then flag conflicts rather than averaging them away. The [research source library structure](/research/research-source-library-structure) keeps reusable source records separate from article-specific conclusions.
