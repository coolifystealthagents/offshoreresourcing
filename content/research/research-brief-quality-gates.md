## Key stats

- A brief is a quality gate, not merely a topic title.
- Explicit acceptance criteria reduce interpretation drift across handoffs.
- Source requirements should be set before claims are drafted.

## Key takeaways

- State the audience, intent, angle, and exclusions.
- List the evidence standard and required source types.
- Define the reviewer and the conditions for rejection.

## Brief checklist

| Brief element | Review question |
| --- | --- |
| Search intent | What decision should the reader make? |
| Evidence | Which primary sources can support claims? |
| Scope | What is intentionally excluded? |
| Acceptance | What must be true before publication? |
